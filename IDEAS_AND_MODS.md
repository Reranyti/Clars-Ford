# Идеи и потенциальные зависимости (обновлено под v1.1010)

> **⚠ Скоро проект полностью изменится (теперь он называется Clars Ford, ранее Lotus Blight). Документ описывает старую версию и скоро устареет. / The project (now Clars Ford, formerly Lotus Blight) is about to change completely; this document describes the old version.**


> Исходный документ был ночным проходом заметок 2026-09-17. С тех пор часть пунктов реализована,
> часть остаётся открытой. Ниже — актуальный статус каждого.

## Зависимости

### TerraBlender — ✅ реализовано

Было "не подключено, требует переписать регистрацию биомов". Сделано: `LotusRegion` регистрирует
`lotus_marsh`/`blessing_tundra` через `Region`/`RegionType` API TerraBlender вместо голого
`BiomeManager`. Мягкая зависимость, как и планировалось.

### Curios API — по-прежнему отложено, статус не менялся

Диагностика из исходной версии документа остаётся верной и не была пересмотрена: `ICurioItem`
резолвится при загрузке класса, что ломает регистрацию предмета для всех без Curios, если
реализовать прямой `implements`. Правильный путь (capability через `AttachCapabilitiesEvent`,
условно по `ModList.isLoaded`) остаётся нереализованным. Линза провидца работает без Curios.

### Ex Meteor Shower — новая зависимость, не было в исходном списке

Подключена для комет StarFall (v1.82.0–1.84.0), в итоге сделана **обязательной** (v1.83.0) по
явному решению — контент StarFall технически не существует без неё, это единственный такой случай
в моде среди всех зависимостей.

## Идеи по развитию — статус

1. **Финальное ядро/концовки** — ✅ закрыто, но не так, как предполагалось. Вместо одного
   финального объекта с бинарным выбором получились три полноценные ветки (Альянс/Война/
   Предательство) с разным контентом на каждой (см. `DESIGN_V2.md`, раздел 1).

2. **Структура "Объект Ноль"** — не реализовано, решение не менялось: точка спавна остаётся без
   структуры.

3. **Звук** — частично закрыто. Появились тематические треки для сюжетных событий
   (`lotus_chase_theme`, `traitor_boss_theme`, `world_lotus_lecture`, `inner_voice_theme`), но
   повседневные звуки спреда (переход фазы, цветение) по-прежнему переиспользуют ванильные
   `SoundEvents.*` не всегда по смыслу — этот конкретный пункт остаётся открытым.

4. **Достижения** — выросло с 12 задуманных до 20 реализованных (см. `BIOMES_DESIGN.md`), включая
   ветку-эксклюзивные (Хончо — только Сопротивление, `alliance_guardian_slaughter` — только
   Альянс). Отдельного полного трекинга "уничтожить" vs "присоединиться" всё ещё нет — решение
   изменилось на трёхветочную структуру, так что и сама идея частично устарела.

5. **Датапак-балансировка** (`SpreadTables`/`InfectionPhases` в JSON) — не реализовано, остаётся
   открытым пунктом, не рассматривалось повторно.

## Новые идеи, появившиеся уже после исходного документа

- **Реальный триггер для сюжетных событий вместо только тестовых команд** — закрыто для Побега
  (порог 5% заражения или 3 дня после выбора ветки) и StarFall (10% или 6 дней), реализовано в
  рамках доработки контента, не было в
  исходном списке идей.
- **Расширение по количеству мобов** — по фидбэку бета-тестеров зафиксировано, что в моде всего
  один по-настоящему уникальный класс сущности (`WorldLotusGuardianWolf`) плюс переодетые ванильные
  мобы в босс-файле (Wolf, Stray) и Хончо (на основе Zombie). Остаётся открытым направлением для
  роста контента.

## Не проверено / требует отдельного захода — не менялось

- Точная стоимость интеграции Curios API всё ещё не проверена глубже диагностики выше.
